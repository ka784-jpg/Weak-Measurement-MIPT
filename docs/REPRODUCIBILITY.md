# Reproducibility

The checked-in Julia environment, seeded examples, source hashes, and automated
tests make the small examples inspectable and repeatable. The published figures
are historical, much larger calculations; they are not generated by the README
command. The repository does not contain the full raw ensembles or an exact
historical environment/seed manifest for every panel.

Recovered sources came from the author's Amarel and AP41 research directories
on 2026-10-24. [source_manifest.json](source_manifest.json) records origin paths
relative to those research roots and SHA-256 hashes. Retrieval date is not a
claim that these are the precise versions used for every published data point.
Original source bytes are unchanged; filenames were made descriptive.

The examples target Julia 1.12.6. A committed Manifest pins packages. RNG streams
and floating-point results can differ across Julia versions and platforms, so
cross-platform tests check physical invariants and within-process repeatability,
not bitwise identity to a stored trajectory. Sources use mutable global state;
run separate workers as processes, not concurrent calls in one Julia session.

Important conventions: entropy is in bits, measurement-record cost is in nats,
and time is a single gate-plus-measurement layer. The historical entropy-variance
drivers record once per two-layer cycle. Keep these conventions distinct when
comparing datasets. Continuous probability densities and discrete outcome
probabilities are also not interchangeable in entropy-of-record calculations.

To validate a fresh checkout:

```sh
julia --project=. -e 'using Pkg; Pkg.instantiate()'
julia --project=. --startup-file=no tests/runtests.jl
python tests/integrity.py
```

The figure manifest covers the original PDFs and generated previews.
[Figure attribution](figures/README.md) is separate from the code license.
